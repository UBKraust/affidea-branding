## 4. Important conflicts/gaps

1. Affidea Kids specifies blue `#3A79C0`; Affi brand book shows `#4181D0`; parent canonical is `#418FDE`. Portal uses parent canonical unless an admin approves an exception.
2. Barriecito is specified for Affi/Kids but no Barriecito font file was found.
3. Six supplied Affi transparent PNG poses are not present in the central Drive folder.
4. Web/App Assets contains only five files and covers only parent/Clinicile/Biomed variants.
5. `OncoLink_Brandbook_Primary.pdf` and `OncoLink — Brandbook.pdf` contain MedDirect content. Correct OncoLink content is in `OncoLink_Brandbook_Extended.pdf`.
6. OncoLink working tree is approximately 1.9 GB and includes duplicate source/export folders and 112 Archivo font files. It must not be auto-packaged.
7. Several brand folders lack one or more standard variants: web SVG, transparent PNG, print PDF/EPS and white version.
8. Duplicate canonical/archive/lockup files exist in several folders.
9. Data Centres files contain personal contact names and mobile numbers; authentication and no-telemetry rules are mandatory.
10. Centre naming differs between workbooks and brand folders, including Phoenix/Affidea Phoenix, Sunmed/Sanmed and Ludimedical/Affidea Kids.
11. Affi pose `affi_poses_3.png` has a clipped dark fragment at the lower-right edge.

## 5. Candidate brand folders

The Drive includes parent Affidea, Clinicile Affidea, Biomed Scan, Affidea Hospitals master and hospital/location lockups, Affidea Kids, MedEuropa, Phoenix, MedIF Otopeni, Fortius, OncoLink, MedDirect, FeminaCare/Kids combined and other integrated/acquired identities. Presence is not proof of active/approved status; Admin must curate the initial registry.

## 6. Standard pack recommendation

Per active brand, target:

- canonical full-colour SVG;
- canonical transparent PNG at useful digital resolution;
- white SVG/PNG;
- print PDF or EPS;
- source AI where approved for distribution;
- current brand book;
- font package or licensed-access note;
- web/app preview;
- curated ZIP manifest.
