# Source material and visual references

## Canonical source

Google Drive is the source of truth for production assets:

`https://drive.google.com/drive/folders/16hA1bCXCEQxRtWbNWC6apAZDPH7fW8sE`

The implementation must discover, index, preview and download files from Drive according to `docs/06_DRIVE_SYNC_ASSETS.md`. Do not copy the complete Drive library into the application repository.

## Reference files supplied during discovery

The following files were reviewed while preparing this specification, but are not duplicated in this documentation archive because the Drive library remains authoritative:

- `Afiidea_Kids_Brand_Guidelines_2026.pdf`
- `Affidea_kids_brochure_2026.pdf`
- `Logo-Affidea Kids.png`
- `Brandbook_Affi_Affidea_15.05.2025.pdf`
- `affi_poses_1.png` through `affi_poses_6.png`

Before production launch, upload any approved reference that is missing from Drive and place it in the correct governed folder. The six Affi poses were not found in the audited Drive hierarchy. `affi_poses_3.png` also contains a clipped dark fragment near its lower-right edge and must be corrected or explicitly approved before publication.

## Authority rule

If sources disagree, the approved Affidea 2026 guideline wins. Sub-brand variations must be explicitly recorded as approved exceptions; they must not silently replace parent-brand tokens.
