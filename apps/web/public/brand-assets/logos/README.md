# Affidea logo library

This directory is the single web-facing location for approved logo previews used by the Brand Hub.

## Naming

- Use lowercase kebab-case filenames.
- Keep the brand or lockup name explicit (for example, `affidea-hospitals-fundeni.svg`).
- Add a variant suffix only when needed, such as `-white`, `-blue`, or `-part-of-affidea`.

## Formats

- Prefer SVG for the canonical web preview.
- Use transparent PNG only when no verified vector export is available.
- Keep brand books in `../brandbooks`, their covers in `../brandbook-covers`, and fonts in `../fonts`.
- Source AI, EPS, print PDFs, drafts, and duplicate exports stay in Drive and are not exposed by the web app.

## Governance

Every published logo must map to a brand record and carry an approval status in the application data. Replacing a file in this directory should happen only after the corresponding Drive source is approved.
